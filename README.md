# Strumly — Front-end Demo

This is a standalone client-side front-end for an online guitar learning platform (no backend required). Open `index.html` in your browser to view.

Features:
- Landing page with hero, featured courses, and features.
- About page with team cards and animated counters.
- Authentication page with login/register toggle, SSO buttons, password visibility toggle, simulated loading/progress, and toast notifications.

To run: open `index.html`, `about.html`, or `auth.html` in a browser (no server required).
